# Interview 010 — Менеджер НАБОРА сцен (эпик [[idea 40]], Фаза 1)

> Проведено: 2026-07-25 (чат, Криник за клавиатурой). Закрывает **развилку 3** плана
> `plans/18_scene_profiles.md` перед стартом Фазы 1. Формат: закрытые вопросы A/B/C.

## Контекст

Фаза 0 (одна текущая сцена переживает рестарт + FAB «Сцены» → **панель-список**) сделана. Фаза 1 —
держать НЕСКОЛЬКО именованных сцен и переключаться между ними. Перед реализацией нужно закрыть UI/UX
развилки менеджера набора сцен.

## Вопросы и ОТВЕТЫ Криника

### Q1 — Вид меню набора сцен по тапу на FAB «Сцены»
**Ответ: A — Панель-список (как сейчас).** Продолжаем стиль Ф0 (панель-список от левого края, растёт
вверх, как `StreamLayersOverlay`). Список имён сцен, скролл при многих. **Радиалку НЕ возвращаем**
(лагала поверх живого TextureView — причина ухода от неё в Ф0).
> ⚠️ Правит наброски `plans/18_phase1` и `idea 40`, где ещё упоминалась «радиалка становится менеджером».

### Q2 — Набор действий над сценой в менеджере (Фаза 1)
**Ответ: A — Полный набор.** Переключить (тап) / Новая / Дублировать / Переименовать / Удалить.

### Q3 — Переименование и имя новой сцены по умолчанию
**Ответ: A — Диалог + «Сцена N».** Переименование через модальный диалог с полем ввода; новая сцена
получает имя-заглушку «Сцена 2», «Сцена 3»… (следующий свободный N).

## Зафиксированные решения (для реализации Фазы 1)

1. Меню набора сцен — **панель-список** (компонент по образцу `StreamLayersOverlay`/панелей Ф0), НЕ радиалка.
2. Действия: **переключить / новая / дублировать / переименовать / удалить** (полный CRUD + switch).
3. Переименование — **модальный диалог**; дефолтное имя новой сцены — **«Сцена N»**.
4. Порядок сцен в списке (drag reorder) — НЕ в Фазе 1 (не запрошен; отдельная развилка при необходимости).

## Не входит в это интервью (открыто, отдельные развилки)

- **Эффекты перехода между сценами** (фейд/выезд, как в OBS) — новое видение Криника (чат 2026-07-25);
  относится к **Фазе 2 (live switch)**, закрывается своим интервью (набор эффектов / длительность /
  пер-сцена или глобально).
- Экспорт: одна сцена или весь набор, zip с картинками — **развилка 2**, блокирует Фазу 3.

## Цель

Вопрос агента к Кринику перестаёт быть строкой в md, которую нужно найти. Он становится **страницей,
которая сама зовёт голосом и звуком**, принимает ответ в один клик и возвращает его в проект в
машинно-проверяемом виде — так, что дальнейшая работа, зависящая от этого ответа, **не может
стартовать без него**.

Главный урок поля, который здесь важнее HTML: **HTML — это транспорт, а цель — ГАРД.** Правило «место
вопросов — только `interviews/`» нарушают даже агенты, которые его знают (в чате дешевле в моменте),
поэтому первым делается не красивая страница, а механическая проверка «нет висящих вопросов».

## Критерии готовности (проверка наблюдением)

- [ ] **К1.** `node tools/owner.mjs guard` печатает висящие вопросы и выходит `1`; при чистом беклоге —
      пусто и `0`. Гард **проверен на сломанной версии** (`selftest`), включая ловушку подстроки
      (`ЗАКРЫТ` внутри слова «за**крыт**ие» не должен считаться статусом).
- [ ] **К2.** `node tools/owner.mjs render <любое из 15 интервью>` строит самодостаточную HTML-страницу
      без единой внешней загрузки; прогон по ВСЕМ 15 живым интервью — без падений.
- [ ] **К3.** Ответ, отправленный со страницы, оказывается в ТРЁХ местах: исходный md · файл решения
      рядом · копия в архиве с `by` и `at`.
- [ ] **К4.** `node tools/owner.mjs gate <док>` выходит **не-нулём**, когда ответа нет, ответ отклонён
      или текст вопроса изменился после ответа (sha тела разъехался). Любое сомнение = отказ.
- [ ] **К5.** Звук и голос слышны Кринику из другой комнаты; **факт доставки подтверждает Криник
      словами**, а не код возврата процесса.
- [ ] **К6.** Тихие часы работают через полночь (23:00–09:00): проверено на обеих сторонах полуночи.
- [ ] **К7.** Пилот на `interviews/interview_015`: Криник отвечает на 3 вопроса со страницы, агент
      продолжает работу по `bugs/75`, **не задав ни одного уточняющего вопроса в чате**.

> **Критерий приёмки — это К7.** Не «страница открылась», а «владелец ответил, и агенту не пришлось
> переспрашивать» (канон навыка `/owner-reviews`).

## Инварианты (нормативные — контур без них разваливается)

| # | Инвариант | Как держим |
|---|---|---|
| **I1** | md — источник, HTML — производное. **Всегда** | страница строится из документа при каждом вызове; руками её не правим |
| **I2** | Ответ пишется в ТРИ места | `interviews/<док>.md` · `interviews/decisions/<док>.decision.json` · `interviews/decisions/archive/<док>--<ISO>.json` (имя решения ВЫВЕДЕНО из имени документа — общий файл затрёт следующее интервью) |
| **I3** | Одобрение привязано к **sha256 ТЕЛА**, а не к клику | одна функция нормализации `normalizeBody()` на обе стороны; текст изменился после ответа = ответ недействителен |
| **I4** | Гейт стоит на стороне ПРИМЕНЕНИЯ, fail-closed | `gate` отказывает не-нулём, если решения нет, оно `rejected` или sha разъехался. Ответ **никогда** не самоодобряется по таймауту |
| **I5** | Сигнал идёт ПОСЛЕ успешно открытой страницы | зовём Криника из рендерера, когда сервер уже слушает и браузер открыт — иначе класс «позвал, а показать нечего» |
| **I6** | Тихие часы важнее всего, включая явно запрошенный уровень голоса | окно **пересекает полночь** — наивное `from <= now <= to` молчит весь день и орёт всю ночь; у этого сравнения свой гард в `selftest` |
| **I7** | Автономные циклы **копят, а не блокируются** | `queue` паркует документ, `inbox` зовёт ОДИН раз на пачку карточек |

**Ноль внешних зависимостей** — соблазн взять генератор статики велик, выигрыш нулевой. Только stdlib
Node + системные утилиты macOS (`say`, `afplay`, `osascript`, `open`).

## Инструмент: `tools/owner.mjs`

| Команда | Что делает |
|---|---|
| `guard` | ищет висящие вопросы: неотвеченные интервью + вопросы-сироты ВНЕ `interviews/`. Exit 1 при находках |
| `render <док>` | md → самодостаточный HTML в `tools/owner-pages/` (gitignored) |
| `ask <док>` | `render` + локальный сервер (жить секунды: поднялся → записал → умер) + браузер + сигнал; ждёт ответ |
| `gate <док> [--q В1]` | fail-closed проверка: ответ есть, не отклонён, sha тела совпал |
| `queue <док>` | припарковать документ для автономного цикла (не блокируя цикл) |
| `inbox` | одна страница «накопилось N» с карточками, один зов на пачку |
| `selftest` | доказывает, что каждый гард СПОСОБЕН покраснеть (канон: гард, который ни разу не краснел, ничего не доказывает) |

### Разбор живых документов (а не выдуманного формата)

Формат интервью в проекте **разнородный** — это факт, снятый с 15 живых файлов, а не предположение:

- заголовки вопросов: `## В1.` · `### Q1:` · `### Q1.` · `## Q1.` · `### Q1 — ` · и документы вообще без
  заголовков вопросов (001, 006, 011);
- строка статуса: `**Статус:** …` · `> Статус: **…**` · `> **Статус:** …` · инлайн после `·` · отсутствует;
- слот ответа: `**Ответ Криника:**` · `**Ответ:**`; отвеченный — текст на ТОЙ ЖЕ строке или в цитате
  под ним, неотвеченный — пусто или пустая цитата `>`.

**Следствие для гарда:** главный сигнал — СТРУКТУРНЫЙ (пустой слот ответа), а не текстовый (слово в
статусе). Именно текстовый греп однажды промолчал, потому что `ЗАКРЫТ` совпал с «за**крыт**ие».
Классификация: `висит` = статус «ждёт» ИЛИ (статуса нет И есть пустые слоты); `частично` = статус
«отвечен», но остались пустые слоты (предупреждение, не нарушение — так устроено интервью 014).

## Риски и как снимаем (в порядке убывания цены — оплачено полем)

| # | Риск | Снятие |
|---|---|---|
| 1 | **Хеш без договорённости о нормализации** → гейт отказывает ВСЕГДА при зелёных самотестах (страница считала байты файла, отправитель — нормализованный текст) | ОДНА функция `normalizeBody()`, обе стороны зовут её; её алгоритм записан в этом плане и в шапке инструмента |
| 2 | **Инструмент построен, агент им не пользуется** — в тот же день, когда страница заработала, агент пересказал вопросы в чате: чат дешевле в моменте | инструмент считается ПРИНЯТЫМ, только когда в ритуале записана исполняемая команда, показывающая нарушения → `guard` попадает в `AGENT_GUIDE.md`, `/interview`, лупы и `/end-chat` |
| 3 | **Exit 0 ≠ человек получил сигнал** — нативные уведомления молча глушатся настройками фокуса с кодом успеха | обязательный путь — ЗВУК (`afplay`+`say`), он не зависит от настроек уведомлений; доставку подтверждает Криник словами |
| 4 | **Фикстуры не ловят живые документы** — три дефекта рендерера вылезли только на реальных файлах | условие сдачи: прогон по ВСЕМ 15 живым интервью |
| 5 | **Ложная тревога в гарде хуже пропуска** — она учит игнорировать инструмент | исключения явные, с причиной в строке (`tools/owner-guard-exceptions.json`), а не ослабление команды |
| 6 | **Обе темы ОС** — тёмный код на тёмном фоне поймал владелец, а не самопроверка | `prefers-color-scheme` + ручной тумблер темы на странице |
| 7 | **Не-ASCII регулярки:** в Node `\w`/`\b` — ASCII-only даже с `u` | границы через `\p{L}` / `(?!\p{L})` с флагом `u`, иначе гард молча слеп к собственному языку |
| 8 | `git checkout -- <файл>` на документе с ответами Криника = уничтожение его работы (EXP-0030) | первоисточник владельца коммитится ПЕРВЫМ действием после ответа |

## Что делает контур с существующей практикой

Ничего не ломает. Интервью без контура работают ровно как раньше — Криник может по-прежнему вписать
ответ прямо в md, и это **тот же по силе ответ**: `HTML = md = чат` (правило эквивалентности,
`/interview`). Контур — сахар поверх жёсткого канонного правила «место вопросов — `interviews/`», а не
новая обязанность.

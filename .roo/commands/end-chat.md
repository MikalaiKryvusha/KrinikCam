# /end-chat — полное закрытие: прощаемся с этим чатом

Криник закрывает этот чат насовсем; работа продолжится в ДРУГИХ чатах, где сессии стартуют с пустым
контекстом. Выполни рутину закрытия **по порядку**, коротко пиши в чат, что делаешь. Шаги не
пропускай. Шаг упал — остановись, сообщи Кринику, не продолжай вслепую.

Все пути относительно корня проекта (`/Users/kryvusha/ai_sandbox/KrinikCam`).

## Шаг 1. Зафиксировать статус и ЭСТАФЕТУ в STATUS.md

Обнови `STATUS.md`:
- **Что сделано в этом чате** — конкретно, с привязкой к багам/фичам и файлам.
- **Текущая позиция** — что работает, что в работе, где находимся.
- **Эстафета («с чего продолжить»)** — чеклист, написанный для НЕЗНАКОМЦА: следующая сессия не знает
  ничего из того, что знал этот чат. Команды, пути к файлам, что проверить первым, открытые вопросы
  и чьи они. Помни про грабли этой сессии — вынеси их отдельным коротким списком.
- Конвертируй относительные даты в абсолютные (сегодня — `date`).

Сверься с активными документами багов в `bugs/` и отрази их статус. Если в чате родился
переиспользуемый урок — зафиксируй его в `EXPERIENCE.md` (навык `/experience`) ДО передачи эстафеты;
с KAIF 2.1 у урока ОБЯЗАТЕЛЬНА строка `Repro:` (готовая команда), иначе урок не принимается.

**Реестр пар «источник ↔ зеркало»** (`AGENT_GUIDE.md` → «Гигиена документов и текста»): прогони его
команды проверки ПЕРЕД передачей эстафеты — хендофф поверх разъехавшейся пары передаёт следующей
сессии ложь. Минимум: `node .kaif/kaif-core.mjs check` (навыки и их зеркала).

**Бонсай-стрижка (STATUS — сводка, а не летопись; KAIF 2.1):** записи, переставшие быть «сейчас» —
закрытые фазы, завершённые сессии, вышедшие релизы — переносятся ДОСЛОВНО в `PROJECT_HISTORY.md`
(новейшее сверху; переносить, а не переписывать). Затем перечитай, что осталось от `STATUS.md`, двумя
тестами из его шапки («уберу эту строку — ошибётся ли следующий агент?» · «читается ли за один
присест?»; мягкий ориентир — ~200 строк). Оставь файл таким, каким сам хотел бы его найти.

## Шаг 2. Актуализировать README (если реальность сдвинулась)

Приведи `README.md` в соответствие с реальностью: статус фаз, рабочие фичи, инструкции. README
двуязычный (EN/RU) — держи оба языка синхронными. Не выдумывай — отражай только сделанное и
проверенное. Опирайся на текущий README и другие витрины Криника (почерк витрины — его, не агента);
release notes сюда не переноси, у них своя зона (`AGENT_GUIDE.md` → «Гигиена документов и текста»).

## Шаг 3. Пересобрать артефакты

```bash
node tools/readme-pdf.mjs                                          # README.pdf в корень (gitignored)
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
node tools/build.mjs --no-ui                                       # debug-APK
```

> ⚠️ `JAVA_HOME` на JBR обязателен — system java_home вернёт Java 25 и сломает сборку; проекту нужен
> ещё и отдельный JDK 17 под тулчейн (EXP-0020). Сборка должна закончиться `BUILD SUCCESSFUL`.
> Падает — остановись и покажи ошибки (`... 2>&1 | grep "^e:"`), сломанное не коммить.
> `readme-pdf.mjs` падает на отсутствии `md-to-pdf` — один раз `node tools/setup.mjs`.

## Шаг 4. Judge, гард висящих вопросов, коммит и пуш

Прогони `/fable-judge` по заявленным в этом чате «готово» ПЕРЕД пушем — канон KAIF 1.6: judge-проход
предшествует КАЖДОМУ пушу и деплою. REFUTED → работа возвращается в работу, а не в эстафету.

Там же — гард места вопросов, чтобы ни один запрос к Кринику не уехал в эстафету незамеченным:

```bash
node tools/owner.mjs guard      # висящие интервью + вопросы-сироты вне interviews/
```

Найдено висящее — перечисли это в эстафете ЯВНО (следующий чат начнёт с него) и, если Криник
на связи, открой страницей: `node tools/owner.mjs ask interviews/<док>.md`.

```bash
node tools/commit.mjs "<тип>: <краткое описание сделанного за сессию>"
```

`tools/commit.mjs` делает всё разом: бампит build-номер в `version.json`, `git add -A`, коммит с
версионным штампом, пуш в `origin/main`. Стиль сообщения (`AGENT_GUIDE.md`): `feat:` / `fix:` /
`docs:` / `refactor:` / `ci:` + одна строка. Перед коммитом — `git diff --stat`: всё, что ты не
намеревался менять, — СТОП и сначала объясни (git-гигиена KAIF 1.6).

Сообщение коммита завершай строкой соавторства текущей модели сессии, например:

```
Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
```

(`commit.mjs` принимает многострочное сообщение — передавай через `$'...\n...'`.)

## Шаг 5. Прощальный отчёт

Отчитайся Кринику: что зафиксировано, что собрано, хэши коммитов, что запушено, и одним абзацем —
ЭСТАФЕТА: главное, с чего следующий чат должен начать. На этом прощаемся.

## Заметки

- Разница одной строкой: **`/pause` = чат продолжится позже; `/end-chat` = чат прощается.**
- Пуш отклонён (non-fast-forward) — `git pull --rebase`, повтори пуш, затем сообщи Кринику о
  расхождении. `could not read Username` — повтори `gh auth setup-git` (`AGENT_GUIDE.md`).
- README.pdf и APK gitignored — `commit.mjs` их не закоммитит, это нормально.
- Идёт активная RTMP-трансляция — для сборки и git она не мешает, но переустановка APK её прервёт.

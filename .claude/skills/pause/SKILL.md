# /pause — мягкая парковка чата (продолжаем ЗДЕСЬ же)

Временная пауза, а не прощание: Криник намерен вернуться В ЭТОТ чат и продолжить. Весь смысл —
**дешёвая и точная парковка**, без тяжёлых ритуалов. (Полное закрытие — STATUS, коммиты, пуши,
передача эстафеты другим агентам — это `/end-chat-soft` (или срочный `/end-chat-force`), отдельный
навык; KAIF 2.4.)

Все пути относительно корня проекта (рабочая машина с 2026-10-17 — Windows: `D:\work\ai_sandbox\KrinikCam`;
прежняя — macOS: `/Users/kryvusha/ai_sandbox/KrinikCam`).

## Шаг 1. Дойти до логической точки — не паркуйся посреди операции

Закончи наименьший связный кусок работы: дерево должно **собираться зелёным и проходить свои
проверки**. Если ты посреди правки и дерево сломано — точка парковки НАСТУПАЕТ ПОСЛЕ минимального
набора правок, который снова делает его зелёным; скажи об этом в чат и доделай (минуты, не часы).
Ничего нового не начинай.

Быстрая проверка, если трогал код:

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
node tools/build.mjs --no-ui 2>&1 | grep "^e:"    # пусто = компиляция чистая
```

## Шаг 2. Сохранить работу — локально и легко

- Дерево зелёное, но есть незакоммиченное — сделай **локальный коммит БЕЗ пуша**:
  `git add -A && git commit -m "wip: <что> — мягкая парковка"` (+ строка соавторства). Локальный
  коммит ничего не стоит и переживает падение среды; пуш — акт закрытия сессии, он принадлежит
  `/end-chat-soft` / `/end-chat-force`. **`node tools/commit.mjs` здесь НЕ используем** — он бампит build-номер и пушит.
- **НЕ обновляй** `STATUS.md`, README и прочие статус-документы — эта церемония ровно то, что навык
  существует, чтобы пропустить. Средой продолжения служит парковочная заметка в чате (шаг 3).

## Шаг 3. Парковочная заметка — здесь ПАМЯТЬ и есть чат

Напиши в чат одну компактную заметку:
- **Где стоим:** что только что доделано и проверено (строка на пункт).
- **Откуда точно продолжать:** следующее конкретное действие, с именами файлов и команд — так, чтобы
  голое «продолжаем» (на любом языке, на котором говорит Криник) подхватилось без единого перевывода.
- Всё срочное, что Криник должен знать, прежде чем отойдёт (идёт ли эфир, стоит ли APK на планшете,
  запущен ли полигон `node tools/rtmp-server.mjs`).

Дальше — стоп. Никаких действий, никакой фоновой работы.

## Заметки

- Семья одной строкой: **`/pause` = чат продолжится позже; `/end-chat-soft` = доделать как следует,
  потом попрощаться; `/end-chat-force` = схватить главное и попрощаться прямо сейчас.**
- ВОЗВРАТ из паузы — триггер освежения (`AGENT_GUIDE.md` → «Context refresh», KAIF 2.2): прежде чем
  продолжать припаркованную работу, перечитай ядро повторного чтения и обнови свидетельство (маркер
  `.kaif/refresh-marker.json` + цитата в чат) — парковочная заметка говорит, ГДЕ продолжать; освежение
  гарантирует, что продолжаешь по ТЕКУЩЕМУ канону.
- Если пауза неожиданно стала постоянной (Криник не вернулся в этот чат) — ничего не потеряно:
  локальный коммит держит работу, а `/resume` следующей сессии читает дерево и `git log` как обычно.
- Идёт активная RTMP-трансляция на планшете — останавливать её для паузы НЕ нужно (сборка и git к
  устройству не обращаются). Переустановка APK стрим прервёт — для паузы она не требуется.
